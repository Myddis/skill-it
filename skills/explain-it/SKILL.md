name: explain-it
description: Re-explain the last message in simpler words, with the missing context. Use when the user says they don't understand, asks "what?" or "explain that", or a reply clearly didn't land.
---

The last message did not land. Explain it again so a reader who was not following closely understands it on first read.

- **Context first.** Open with one or two sentences on where the work stands and what led to the message: the reader may have lost the thread.
- **Simplified Technical English.** Write in the style of ASD-STE100: short sentences, one idea per sentence, active voice, common words.
- **Project terms.** Use the terms in `GLOSSARY.md` if it exists. Define every other technical term in a few words the first time it appears.
- **Concrete over abstract.** Give an example from this project for each idea that is still abstract.
- **Same substance.** Keep every fact, decision and question from the original message.

Write it shorter than the original wherever you can. If the message described a process of several steps, end by offering to draw it with `visualize-it`.
